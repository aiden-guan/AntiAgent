🚀 Antigravity Integration & Setup Guide
⚡ Should Antigravity be in Turbo Mode?

Yes, absolutely! Turbo Mode (Always Proceed) is the recommended setup when using AntiAgent.

Normally in Antigravity, Turbo Mode bypasses interactive confirmation dialogs to let the AI build fast. However, AntiAgent registers as a native PreToolUse lifecycle hook directly in Antigravity's core runtime. Every tool call is analyzed before execution.

• Safe tools (reads, tests, routine edits): Auto-approved with zero latency.
• Potentially dangerous tools: AntiAgent issues force_ask, which overrides Turbo Mode and forces Antigravity to pause and ask for your approval.
• Catastrophic threats (root wipes, credential leaks, curl|bash): Hard-denied immediately.

⚙️ Antigravity: Always Proceed / Turbo 🛡️ AntiAgent Profile: Balanced (Recommended) 🔒 Protection: force_ask override
