🛡️ Welcome to AntiAgent — Setup & Turbo Mode Guide
⚡ CRITICAL SETUP: Set Antigravity to Turbo Mode (Always Proceed)

AntiAgent is designed to operate with Antigravity in Turbo Mode ("Always Proceed").

Normally, running AI coding assistants without guardrails requires either tedious manual prompts for every simple command, or risking unmonitored execution in Turbo Mode. AntiAgent solves this by embedding directly into Antigravity's PreToolUse lifecycle hook.

🛡️ How AntiAgent protects you in Turbo Mode:
  • ⚡ Harmless Actions (ls, cat, git status, tests): Auto-approved instantly so Antigravity works at full Turbo speed without interruptions.
  • 🛑 Dangerous Actions (git push --force, rm -rf, secrets access): AntiAgent issues a native force_ask verdict that overrides Turbo Mode, pausing execution and prompting you for manual confirmation!
  • 🚫 Catastrophic Threats (root wipes, curl | bash): Hard-denied on the spot with clear explanation.
👉 How to set Turbo Mode in Antigravity:
• In Antigravity IDE: Click the execution mode toggle in the chat prompt bar (look for the ⚡ lightning bolt icon) and select Turbo / Always Proceed.
• In Antigravity CLI: Launch tasks with agy --turbo or set always_proceed: true.
