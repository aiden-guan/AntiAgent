          AntiAgent Setup & Turbo Guide
        

        
      


      
      

        

          
          RECOMMENDED: Enable Turbo Mode (Always Proceed) in Antigravity
        

        

          
AntiAgent is specifically architected to let you run Antigravity at full velocity without dangerous blind spots.

          

            
How AntiAgent protects you in Turbo Mode:

            
    
              
  • ⚡ Harmless Actions (ls, cat, git status, unit tests): Auto-approved instantly so you never wait for prompts.
    • 
              
  • 🛑 Destructive Actions (git push --force, rm -rf, viewing secrets): AntiAgent issues a native force_ask that overrides Turbo Mode and pauses execution for confirmation!
    • 
              
  • 🚫 Catastrophic Threats (root wipes, piped bash scripts): Hard-denied immediately with explicit reason.
    • 
            

          

          

            
How to set Turbo Mode in Antigravity:

            

              • In Antigravity IDE: Click the execution toggle in the prompt bar (⚡ lightning icon) and select Turbo / Always Proceed.

              • In CLI: Launch tasks with agy --turbo or set always_proceed: true.
